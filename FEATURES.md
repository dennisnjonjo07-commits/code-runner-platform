## 📁 Project Management

### Create Project
```
1. Click "+ New Project"
2. Enter project name
3. Select language
4. (Optional) Paste code
5. Click "Create"
```

### Upload Files
```
1. Select project
2. Click "📤 Upload Files"
3. Choose files
4. Click "Upload"
```

### Edit Code
```
1. Select file from tabs
2. Edit in editor
3. Click "💾 Save"
4. Code saved automatically
```

### Deploy Live
```
1. Click "🚀 Deploy Now"
2. Wait for build (30-60 seconds)
3. Get live URL
4. Share with world!
```
